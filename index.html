02 · Conversion

AutoCAD → native Revit

Consultant and IFC details arrive as DWG. I rebuild them as real Revit content (lines, filled regions, text and live dimensions) in the project's own standards and title block. They are never linked or exploded CAD.

My conversion pipeline

  1. DWG → DXF through the AutoCAD core console, batch and headless.
  2. Split by viewport: each detail is extracted with its title, scale and notes.
  3. Map to the model's standards: layers to line styles, lineweights, greys, line patterns, text styles and dimension types.
  4. Rebuild natively: detail lines, filled regions, text with the original alignment and fonts, and real dimensions with the original rounding.
  5. Dry run and image check against the source PDF before anything is committed.
  6. Sheet in team format: title block, revision, viewport titles, issued as PDF.

04 · Families

Revit families: built, generated, nested

I work inside the Family Editor and I also write code that builds families: reference planes, locked and equal dimensions, formulas, type catalogues, voids, materials and nested components.

Family generation

From a spec to a real .rfa

Engineers draft a family in the company ERP (parameters, types, materials, solids). My Revit add-in builds it as a real family and uploads it back to the shared library.

ERP spec→params · types · formulas→solids · voids · materials→.rfa
  • Every parameter and type, in the right groups, with formulas; a formula Revit refuses becomes a per-type value and is reported
  • Extrusions and revolutions tied to parameters, yes/no visibility, and voids that cut
  • One codebase for Revit 2022–2026, with a formula engine cross-tested against the web version
Parametric by code

Opening families that flex

BWIC Openings creates its own families from the Generic Model template: wall and floor openings, rectangular and round.

  • Reference planes, aligned and locked dims, EQ constraints, and labelled width, height, diameter and depth
  • A void that cuts the host plus a matching visible solid on its own subcategory, switchable per instance
  • Flex-tested before saving; if Revit refuses a parametric profile, it falls back to fixed sizes automatically
  • Cached per Revit version and loaded straight into the project
Nested & editing

Nested and shared families

I build families from components: nested and shared families with their parameters passed up to the host, so one family drives many parts.

  • Nested and shared components with linked parameters, visibility and type control
  • Opens loaded families from the project and reads every parameter, formula, subcategory and visibility setting
  • Works with nested parts in the model: vanity heights measured through their nested families, drains placed on their nested reference planes
  • Places families in bulk: 89 shadow-gap families, stiffener columns, opening families
